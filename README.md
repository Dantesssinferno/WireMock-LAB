# WireMock LAB

REST API mocking laboratory.

# Project Goals

- Learn WireMock
- Create API stubs
- Simulate positive and negative scenarios
- Practice backend testing

## Features

- Successful wallet deposit
- Currency validation
- Token validation
- Timeout simulation
- Service unavailable simulation
- Duplicate transaction
- Amount validation

docker compose up -d

http://localhost:9090
